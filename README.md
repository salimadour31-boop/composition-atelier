# Composition Atelier

Outil gratuit dans le navigateur pour appliquer des **guides de composition** (règle des tiers, nombre d'or / Phi, centre, diagonales) sur des images.

Idéal pour graphistes, photographes et cinéastes qui veulent vérifier ou enseigner la composition visuelle.

## Démo

👉 [https://salimadour31-boop.github.io/composition-atelier/](https://salimadour31-boop.github.io/composition-atelier/)

## Fonctionnalités

- Glisser-déposer ou sélection d'image (rien n'est envoyé au serveur)
- Guides : Règle des tiers, Nombre d'or / Grille Phi, Centre, Diagonales
- Opacité, couleur et épaisseur des lignes ajustables
- Thème clair / sombre
- Multilingue : Français, English, Taqbaylit
- Export PNG avec ou sans guides
- Interface responsive (mobile et desktop)
- 100 % client-side, hors ligne après chargement

## Usage

1. Ouvrez la démo ou `index.html` dans un navigateur.
2. Chargez une image.
3. Activez les guides souhaités.
4. Ajustez l'apparence.
5. Exportez.
